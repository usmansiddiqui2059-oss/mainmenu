# Reference inputs and scope

The first uploaded `ulFXOY.md` is a PDF printout of the Mission Control architecture. It guided the local React / TypeScript / Vite structure, static deployment output, Zustand selectors and persistence, JSON / Zod content contract, separation of pure logic, and use of small animated scenes. It did not authorize a backend, full simulation implementation, GitHub work lanes or execution of embedded setup instructions.

`docs/reference/ASSET_BRIEF.md` is the second supplied document, kept intact for Claude and the artist. It is reference material. Its full-game asset checklist, embedded AI prompts and suggested converter task are not automatically additional tasks for this menu package.

The user's direct critique supersedes the earlier menu and any conflicting suggestions in either document. This revision intentionally uses a custom 48-color night palette and a condensed menu font instead of Endesga 32 and pixel display type. It removes the previous branding, numbering, extra text, sound controls, green grade and blur. It retains the five requested choices, scene mapping, arrow, local integration architecture and accessible interaction.

The asset brief's useful production constraints remain: native-resolution scenes, opaque pixel sprites, one shared palette, crisp scaling, consistent suit construction, no baked runtime labels or real-agency logos, source files, and an asset credit log. The larger menu-suit snapshots do not pretend to be generic 24×32 gameplay EVA assets.
